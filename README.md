# アルピニスト・ダッシュボード サポートサイト

Wear OS とスマートフォンのアプリ「アルピニスト・ダッシュボード」のサポートページとプライバシーポリシーです。

- サポートページ → `index.html`
- プライバシーポリシー → `privacy.html`

Google Play の申請では、プライバシーポリシーのURLの提出が**必須**です。

## 編集について

**プライバシーポリシーの原本はアプリ本体のプロジェクトの `docs/` フォルダにあります。**
内容を変えるときはそちらを編集し、このリポジトリへコピーしてください。

```
C:\Claude\IDEAs\Project summit\Wear os\docs\privacy.html  →  ここ
```
